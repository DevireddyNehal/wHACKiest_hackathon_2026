Commands and privacy

Speak naturally: “Could you open AirTouch?”, “please show SynapseWeb”, “run a comparison”, “search my notes for LLM”, or “scroll down”. AuraOS shows the transcript and asks you to confirm before acting.

The microphone starts only after you click. Audio is streamed securely to the AuraOS backend and recognized locally; it is not sent to a speech provider. Check the transcript and confirm before any voice action runs. Voice cannot book, pay, or send messages.

01 / SMARTPOINT
How to demo SmartPoint
  1. Highlight a line in the practice card, then click Use highlighted text.
  2. Click Analyze this snippet. The result uses only that text and says when a price cannot be verified.
  3. Click Save this to Rewind, then open RewindWeb. On another page, the extension does the same with Alt+S.

01SmartPoint Desk mode

Highlight a line, or paste one. AuraOS explains only that text and says when it is too thin to trust a price.

02 / AIRTOUCH
How to demo AirTouch
  1. Click Enable pointer demo.
  2. Move over one of the practice tiles to aim the virtual laser.
  3. Click Simulate pinch to select it. This preview uses pointer input only, not a webcam.

03 / SYNAPSEWEB
How to demo SynapseWeb
  1. Paste two or three listing snippets, separated by a blank line. Leave that box empty for a labeled sample.
  2. Click Compare these snippets or Run sample comparison.
  3. Read the stated price, fees written in the text, and what the text never says. Save the table to RewindWeb.

03SynapseWeb Your text or a sample

Paste listing text to compare only what those snippets say. An empty box runs a labeled sample with fictional prices. No site is opened.

⌘

A comparison preview will appear here. No websites are queried, no cart is prepared, and no booking can be made.

Let the reminder wait for you

Create a reminder template and trigger a local alert preview when you choose.

04 / GHOSTBUTLER
How to demo GhostButler
  1. Create a reminder template and optionally choose a time.
  2. At or after that time, choose Preview alert and confirm.
  3. Allow notifications if the browser asks. You get an in-app preview and, on this open tab, a browser notification. Nothing is booked or sent externally.

04GhostButler Manual demo only

Reminders stay in this server process. After you confirm a due reminder, this open tab can show a browser notification. Nothing is monitored, booked, or sent externally.

05 / REWINDWEB
How to demo RewindWeb
  1. Search for LLM or hackathon to filter the sample notes.
  2. Save a note here, or use Save this to Rewind on a SmartPoint or SynapseWeb result.
  3. Restart the backend and search again. Saved notes remain in a local file; sample notes are examples only.

05RewindWeb Text-only memory

Search uses simple keyword matching in this prototype, not embeddings. No automatic history, screenshots, cookies, or page states are collected.
