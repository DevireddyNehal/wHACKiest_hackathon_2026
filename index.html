Voice agent

Give a short command to navigate or run a safe demo action.

Microphone is off. Type a command or start listening.

Commands only use the words you say; the page does not capture surrounding content.

Commands and privacy

Try “open SmartPoint”, “run comparison”, “analyze this snippet”, “turn on AirTouch”, “search notes for LLM”, or “scroll down”.

The microphone starts only after you click. Browser speech recognition may process audio through your browser provider; only the recognized command is sent to AuraOS. Reminder alerts still require manual confirmation, and voice cannot book, pay, or send messages.

01 / SMARTPOINT
How to demo SmartPoint
  1. Edit the selected text and your question, or keep the sample.
  2. Click Analyze this snippet to see a bounded explanation.
  3. In the optional extension, hover over an element and press Alt+S; no full-page content is sent.

01SmartPoint Desk mode

A micro-comprehension demo for confusing terms, prices, or page copy. No browser content is captured automatically.

Only this excerpt and your question are sent to the local backend (max 2,500 characters). With an OpenAI key configured, the backend forwards it to OpenAI.

02 / AIRTOUCH
How to demo AirTouch
  1. Click Enable pointer demo.
  2. Move over one of the practice tiles to aim the virtual laser.
  3. Click Simulate pinch to select it. This preview uses pointer input only, not a webcam.

02AirTouch Air mode

Move your pointer over the stage to aim. The demo maps pointer movement to a virtual laser and simulates pinch-to-select.

04 / GHOSTBUTLER
How to demo GhostButler
  1. Create a reminder template and optionally choose a time.
  2. At or after that time, choose Preview alert.
  3. Confirm the dialog to show an in-app preview. Nothing is booked or sent externally.

04GhostButler Manual demo only

Missions are stored in memory while this server runs. There is no background scheduler, portal monitoring, queue bypass, booking, WhatsApp dispatch, or payment flow.

05 / REWINDWEB
How to demo RewindWeb
  1. Search for LLM or hackathon to filter the sample notes.
  2. Optionally save a title and short excerpt that you choose.
  3. Use the timeline slider to select a visible text record. Search is keyword-based; no page snapshots are stored.

05RewindWeb Text-only memory

Search uses simple keyword matching in this prototype, not embeddings. No automatic history, screenshots, cookies, or page states are collected.
